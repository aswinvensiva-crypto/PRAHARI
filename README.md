# PRAHARI

**P**redictive **R**outing & **A**I for **H**otels, **A**ttractions, **R**egions & **I**tineraries: an AI platform that forecasts tourist demand, measures each destination's live carrying capacity, and redirects surplus travellers to nearby under-used destinations and small hotels.

Smart India Hackathon, Student Innovation (Travel & Tourism). The complete idea-submission package is in [`SIH_Submission/`](SIH_Submission/README.md).
