# PRAHARI: SIH Idea Submission Package (Student Innovation, Travel & Tourism)

**Problem Statement:** Student Innovation. A solution or idea that can boost the current situation of the tourism industry, including hotels, travel and others.

**Final idea:** PRAHARI: AI Demand Forecasting & Crowd Rebalancing to Boost Hotels, Homestays and Travel in India
**Tagline:** Predict. Protect. Redistribute.

> Deadline from the evaluator guide: **30 September 2026, with no extensions.** Submit a day early, because portals slow down near deadlines.

## Final checklist before you click Submit

### Content quality (from the evaluator guide)
- [x] **Research backing:** academic citations (Song & Li 2008, Lim et al. 2021, Cifuentes 1992, UNWTO 2018 and others), government reports (India Tourism Statistics 2024, schemes)
- [x] **Technical credibility:** realistic 36-hour timeline, justified technology choices, clear architecture
- [x] **Innovation factors:** 30%+ differentiation argued, novel use of known tech, IP potential (D-CCI method, rebalancer)
- [x] **Writing quality:** professional government-proposal tone, consistent structure, and a forward-looking closing line in each section
- [ ] **Fact-check:** one team member should verify every statistic against the latest official source (see "Facts to verify" below)

### Avoid these elimination triggers
- [x] Not a generic solution: this is not "another chatbot"
- [x] Realistic scope: the hackathon build covers one cluster (Kullu-Manali plus 4 twins)
- [x] No buzzword overload: every technology is justified; no blockchain
- [x] Character limits respected (see the table above)
- [x] File format PDF, under 5 MB
- [x] No college or institution name in the title, documents or video script
- [ ] **YouTube link works:** set the video to Public or Unlisted and test it in an incognito window
- [ ] **Team composition:** 6 members, including **at least one female member** (SIH requirement)
- [ ] **College SPOC approval / authorisation letter** ready
- [ ] Team is submitting to **no more than 2 Problem Statements**
- [ ] Submitted **before 30 Sept 2026**
- [ ] Insert the **PS number** from the portal wherever `[Insert the SIH PS number]` appears (in `04_Business_Model_Canvas.md`, if you use it)
